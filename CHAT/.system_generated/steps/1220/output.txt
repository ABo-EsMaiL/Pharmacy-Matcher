The search for ""https://transform.unstructured.io" extract schema parse_id" returned the following summary:
To extract data using Unstructured's API with a defined schema, you typically utilize the `structured_data_extractor` within a workflow job[1][2].

### How to Use Extraction with Schema
The `parse_id` is generally associated with the result of a partitioning or processing job[3]. When using the API for structured extraction, you define your requirements in a JSON schema and include them in the `job_nodes` configuration of your request[2].

#### Example API Request Structure
You can perform extraction by sending a `POST` request to the Unstructured API. Below is the conceptual structure for a job that performs both parsing and structured extraction[2]:

```json
{
  "job_nodes": [
    {
      "name": "Partitioner",
      "type": "partition",
      "subtype": "vlm",
      "settings": { "is_dynamic": true, "allow_fast": true }
    },
    {
      "name": "Extractor",
      "type": "structured_data_extractor",
      "subtype": "llm",
      "settings": {
        "schema_to_extract": {
          "json_schema": {
            "type": "object",
            "properties": {
              "field_name": { "type": "string" }
            },
            "required": ["field_name"]
          },
          "extraction_guidance": "Instructions for the model..."
        },
        "provider": "openai",
        "model": "gpt-5-mini"
      }
    }
  ]
}
```

### Key Steps
1.  **Define Your Schema**: Your schema must conform to **OpenAI’s Structured Outputs guidelines**[1]. Note that there is a maximum nesting depth of 10 levels for JSON schemas[1].
2.  **API Integration**: Use the `/jobs/` endpoint to submit your document and your `job_nodes` configuration (as shown above)[2].
3.  **Extraction Methods**: In the Unstructured UI or API, you can choose between **LLM** (default) or **Regex** methods for extraction[1].
4.  **Workflow**: If you are using the Unstructured web interface, you can define your schema visually in the **Define Schema** pane after uploading a file[1][4]. The "Get Code" feature in the UI can also generate the specific API request code for your defined workflow[3][5].

For detailed implementation, refer to the [Unstructured API reference documentation](https://docs.unstructured.io/api-reference/workflow/workflows)[6].
