The `unstructured-transform-client` is a Python package available on PyPI that serves as a client for the **Unstructured Transform v2 API**[1][2].

### Key Details
*   **Purpose:** It is designed to facilitate the conversion of unstructured files (such as PDFs, emails, images, and scanned documents) into structured data[2][3][4]. This structured output is optimized for use in AI applications, vector databases, and other downstream data pipelines[3][4][5].
*   **Functionality:** The library handles tasks like document partitioning, enrichment, chunking, and embedding[3][4].
*   **Integration:** It is closely related to the broader "Unstructured" ecosystem, which provides tools for ingesting and preprocessing complex documents for LLMs (Large Language Models)[4][6].

### Note on Usage
While `unstructured-transform-client` exists as a specific package for the Transform v2 API[1], official documentation for Unstructured's operations and SDKs often references the `unstructured-client` package (e.g., `pip install "unstructured-client>=0.46.2"`) for general API interactions[7]. 

If you are looking to integrate document processing into AI agents, you may also encounter the **Unstructured Transform MCP (Model Context Protocol) server**, which allows AI agents to interact with the Unstructured Transform platform using standard protocols[3][4][8].
