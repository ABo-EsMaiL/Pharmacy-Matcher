انسخ هذا الـ Prompt كما هو، وضعه لجيمناي مع النص أو صورة الصفحة:

```text
أنت خبير صيدلي متخصص في استخراج بيانات فواتير وقوائم الأدوية.
قم باستخراج جميع أسماء الأدوية والمنتجات الطبية الموجودة في هذا المحتوى/الصورة بدقة كاملة.

القواعد الصارمة:
1. انقل اسم الصنف كاملاً في حقل واحد (item_name_raw) متضمناً: الاسم التجاري، والتركيز، والهيئة الدوائية (أقراص، شراب، كريم، أمبول، نقط...) وأي ملاحظات تابعة لاسم الصنف.
2. استخرج أسماء الأدوية فقط، وتجاهل تماماً: أسعار البيع، الخصومات، الكميات، أرقام الأكواد، أو إجماليات الفاتورة.
3. اكتب الحروف باللغة العربية السليمة (مثال: استخدام الكاف العربية "ك" بدلاً من الفارسية "ک"، والباء "ب" بدلاً من "پ").
4. لا تخترع أدوية غير موجودة ولا تترجم الأسماء.

أخرج النتيجة بصيغة JSON فقط بهذا الشكل وبدون أي مقدمات أو شروحات:
{
  "items": [
    {
      "item_name_raw": "اسم الصنف كامل بالتركيز والهيئة",
      "source_page": 1
    }
  ]
}
```
