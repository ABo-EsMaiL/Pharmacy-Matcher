The search for ""https://api.unstructured.io" "structured_data_extractor"" returned the following summary:
The `structured_data_extractor` is a core component within the Unstructured.io platform and API designed to transform unstructured documents (such as PDFs, emails, and forms) into clean, structured JSON output[1][2][3].

### Key Concepts
*   **Purpose:** Unlike standard partitioning, which converts files into generic document elements, the `structured_data_extractor` allows you to define a specific target JSON schema[2]. It then extracts only the precise data fields you require from your source files[4][2].
*   **Methods:** It supports two primary subtypes for extraction[5][3]:
    *   **LLM (Large Language Model):** Uses language models to extract data based on a provided JSON schema or plain-language extraction guidance[6][2].
    *   **Regex:** Uses regular expression patterns to identify and extract specific data, such as prices or ID numbers[7][8][3].

### Usage in the API
When using the Unstructured API, the `structured_data_extractor` is typically configured as a node within a job's processing pipeline[9][5]. 

**Example Configuration Snippet:**
In API requests, you define the extractor within the `job_nodes` array[9][10]:

```json
{
  "name": "Extractor",
  "type": "structured_data_extractor",
  "subtype": "llm",
  "settings": {
    "schema_to_extract": {
      "json_schema": { ... },
      "extraction_guidance": "..."
    },
    "provider": "openai",
    "model": "gpt-5-mini",
    "output_mode": "extracted_data_only"
  }
}
```

### How to Access
*   **API/SDK:** You can integrate the extractor programmatically using the Unstructured Python SDK or by sending requests directly to the Unstructured API[9][3].
*   **UI:** It is also available via the Unstructured workflow designer and the Start page for local file processing[5][3].
