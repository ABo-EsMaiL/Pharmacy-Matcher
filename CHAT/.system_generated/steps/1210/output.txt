The search for ""unstructured-transform-client" parse document extract python" returned the following summary:
The `unstructured` library and its associated `unstructured-client` (often used via the `unstructured-client` Python SDK) are designed to parse complex documents (PDFs, DOCX, HTML, images, etc.) and extract structured data[1][2][3].

### Core Concepts
*   **Partitioning:** The process of breaking a document into "elements" (e.g., `Title`, `NarrativeText`, `ListItem`, `Table`, `Image`)[4][2].
*   **Extraction:** The newer "Extract" workflow allows you to pull specific fields as structured data directly from those documents[5][3].
*   **Modes:** 
    *   **Local:** Uses local processing (no API costs) but may require system-level dependencies for complex file types[1][6].
    *   **API:** Uses the Unstructured API for advanced AI-based OCR and complex layout analysis[1][7].

---

### Basic Usage Patterns

#### 1. Using the `unstructured` Library (Local)
For local partitioning, you primarily use the `partition` function[8].

```python
from unstructured.partition.auto import partition

# Partition a document into elements
elements = partition(filename="example.pdf")

# Iterate through and print elements
for element in elements:
    print(f"{element.category}: {element.text}")
```

#### 2. Using the `unstructured-client` (API)
When using the SDK to interact with the Unstructured API for more advanced processing or extraction, you typically use the `UnstructuredClient`[3][6].

```python
import os
from unstructured_client import UnstructuredClient
from unstructured_client.models import operations, shared

# Initialize client
client = UnstructuredClient(api_key_auth=os.getenv("UNSTRUCTURED_API_KEY"))

# Example: Using the SDK to parse a file
with open("document.pdf", "rb") as f:
    req = operations.PartitionRequest(
        partition_parameters=shared.PartitionParameters(
            files=shared.Files(
                content=f.read(),
                file_name="document.pdf",
            ),
            strategy="hi_res", # Uses AI-based partitioning
        ),
    )

res = client.general.partition(request=req)
```
