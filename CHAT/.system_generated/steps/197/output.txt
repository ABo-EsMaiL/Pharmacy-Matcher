An API key with the prefix `oc_sk_` is a format used by several different services for authentication via Bearer tokens[1][2][3]. Because this prefix is used by multiple platforms, the specific service depends on the context in which you encountered the key:

*   **Orbit Commerce:** Orbit uses `oc_sk_` for store API keys, which merchants create to connect their own systems (like ERP or warehouse software) to the Orbit API[4][5].
*   **OpenCode:** The OpenCode Console uses `oc_sk_` for service account API keys to authenticate requests to its Usage and Inference APIs[6][7].
*   **OpenClaw CRM:** OpenClaw uses `oc_sk_` prefix API keys for its REST API, which allows AI agents and other integrations to interact with the CRM[1][8].
*   **Omniloy (OlivIA):** The OlivIA API also utilizes `oc_sk_` personal API keys for authentication[2].
*   **ShipmentBot (OpenClaw SellerCentral API):** This service uses `oc_sk_` bearer tokens to scope API access to specific seller business contexts[3][9].

### Important Security Note
Regardless of the service, an API key starting with `oc_sk_` is a **secret credential**[10][11]. 
*   **Keep it private:** Never share it, commit it to public repositories (like GitHub), or include it in client-side code (browsers or mobile apps)[10][12].
*   **Usage:** These keys are intended to be used in server-side environments[10][11].
*   **Exposure:** If you believe your key has been exposed, you should immediately revoke it in the respective service's dashboard and generate a new one[4][12].
